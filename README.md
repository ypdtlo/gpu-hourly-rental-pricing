# GPU按小时租用：不用包年包月，跑AI绘画、渲染和云游戏该怎么挑机器、一小时大概多少钱

搜「GPU按小时租用」的人，需求通常很具体。要么是包年包月太贵，要么是根本用不了那么久——跑一组 Stable Diffusion 出图、压一段 4K 素材、给模型做一次推理压测，或者周末玩两小时云游戏。这些活的算力需求按小时算很小，按月算就是白花钱。

国内的显卡云（GPU 云服务器）里，雨云的做法比较有代表性：机器按月挂在账号下，GPU 只在开机的时候走小时计时，关机就停表。下面把它的计费逻辑、目前公开的机型配置和价格，以及「一小时到底多少钱」这笔账算清楚。

## 先分清两种「按小时」

市面上的按小时 GPU 租用大致是两类，别混着比价。

一类是**整卡独占按小时**，海外平台居多。公开报价里，L4（24GB）在 Vast.ai 约 $0.33/小时，RunPod 的 Community Cloud 是 $0.44/小时，Northflank 和 Modal 都是 $0.80/小时（Modal 的 CPU 和内存还要另外计费）；再往上，Anyscale 公布的 A100 是 $4.96/小时、H100 是 $9.29/小时。显存独享，适合训练和微调，代价是单价高、网络在境外。

另一类是**vGPU 分片 + 开机计时**，国内厂商走得更多。显卡被切成 1G、2G、4G、8G 显存等不同档位分配出去，单价低得多，适合推理、出图、渲染、云游戏这类消费级负载。

雨云属于第二类，但计费结构还要再拆一层。

## 雨云的按小时怎么算：月固定费 + 开机计时

以深圳、广州的显卡云机型为例，它有两种计费模式：

- **日常网吧型**：每月先付一笔固定的小钱，深圳 V100 机型是 28 元/月，广州 RTX3080 机型是 29 元/月；开通时赠送 5 小时；之后开机按 2.5 元/小时计费，关机不计时。加时也可以打包买：1 小时 2.5 元、5 小时 12 元、24 小时 50 元。这类机型的公网 IP 随开机动态生成。
- **算力长租型**：月付一口价，不限制开机时长。深圳 V100（16 核 / 24GB 内存 / 16G 显存 / 50M 上传 200M 下载）638 元/月起；广州 RTX3080（12 核 / 24G 内存 / 10G 显存 / 200Mbps 不限流量 / 150Gbps 防御）978 元/月，年付 7 折约 9013 元/年，折合每月约 751 元。

把小时价换算一下就清楚了。2.5 元/小时大约是 0.35 美元，和 Vast.ai 的 L4 报价基本同档；如果一次开满 24 小时，打包价 50 元相当于 2.08 元/小时。硬件代际上，P40、V100、RTX3080 确实不是 L4、A100 那一批新卡，但落到「每小时花多少钱、能拿到多少显存」这个比值上，跑出图、渲染、云游戏是够用的。

> 关机不计时是这类机型最关键的条款。开着不用、忘了关的那几个小时，才是按小时租 GPU 最容易漏掉的成本。

## 按小时租来的显卡，具体能跑什么

**AI 绘画。** P40 机型的显存以 vGPU 形式切分，1G 到 8G 都能选。跑 Stable Diffusion 出图，4G 显存档（小型工作+）是能用的起点；官方论坛的搭建教程也建议直接上旗舰档，因为不少 AI 模型的最低要求就是 8G 内存/显存。宁波 P40 机型默认已装好 NVIDIA 驱动，CUDA 版本 12.2。

**模型推理和调参。** 官方评测里用 PyTorch 跑 4096×4096 矩阵乘法测试，P40 机型耗时在 50 毫秒左右，切回 CPU 跑要 300 毫秒上下——这就是按小时租一张卡和用 CPU 硬扛的区别。

**3D 渲染、视频转码、云游戏。** 雨云对 RDP 做过针对 GPU 的优化：启用了 NVIDIA 的 RDP OpenGL 支持，远程桌面里可以直接调 GPU 跑 OpenGL 软件；H264/AVC 硬件编码也开了，看视频走硬件编码；帧率上限从默认 30FPS 提到 60FPS。RTX3080 和 V100 机型配 200Mbps 带宽，本来就是奔着云游戏和串流去的。

**不适合的场景也说清楚。** 多卡大模型训练、需要显存独占的 MIG 类任务，vGPU 分片机型不合适。另外大陆机房对 HTTP 业务有域名备案 + 过白的要求，NAT 机型没有独立公网 IP，共用公网 IP 最多配 10 条端口转发，只适合做私服这类用途。

## 几个常被问到的点

**关机会继续收钱吗？** 日常网吧型关机不计时，只保留每月那笔固定费用；长租型本身不限开机时长，关不关一个价。

**一小时 2.5 元算贵吗？** 放在海外整卡按小时的报价里看，大概处在 Vast.ai 一档，低于 RunPod、Northflank、Modal 的同级报价；但硬件代际不同，P40/V100 是更老的架构，别拿它和 A100 的算力单价直接对齐。

**什么时候该切长租？** 算临界点。深圳 V100：固定 28 元/月，长租 638 元/月，差 610 元，除以 2.5 元/小时，约 244 小时。也就是每月开机超过 244 小时，长租才更划算。广州 RTX3080：固定 29 元、长租 978 元，差 949 元，临界点约 380 小时。低于这个数字，按小时开机就是更便宜的那一侧。

**为什么不用海外整卡，价格看着还更低？** 国内机房的价值在于延迟和可用性：本地网络直连、不需要额外处理网络环境、Windows + RDP 开箱可用、支持免备案节点以外的国内线路。如果你的任务只是本地出图、远程桌面渲染，海外整卡的额外折腾成本往往比省下的那点小时费更贵。

## 怎么选，一句话版本

每月开机个位数小时、想试跑模型或出图——选日常网吧型，28~29 元月固定费加 2.5 元/小时，是最接近「纯按小时租 GPU」的形态。每月开机稳定超过 250~380 小时——直接上算力长租型，不用再盯着表算。要跑训练或需要独占显存——这类分片机型不是答案，别硬套。
